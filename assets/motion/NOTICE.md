# Motion guide image source

The start and finish photographs in this directory come from the
[Free Exercise DB](https://github.com/yuhonas/free-exercise-db) project.

The source dataset is released into the public domain under the Unlicense.
The local copies are used as two-frame movement references and retain their
original exercise directory identifiers and filenames.

The custom Face Pull motion sprite is stored separately at
`assets/equipment-machine-face-pull-guide-v2.png`.
